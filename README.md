# Student Management System

A console-based Student Management System developed using Java, JDBC, and MySQL.

## Features

- Add a new student
- View all student records
- Search student by roll number
- Update student details
- Delete student records
- Display total student count
- Validate user input
- Check duplicate roll numbers and email addresses

## Technologies Used

- Java
- JDBC
- MySQL
- IntelliJ IDEA
- Git and GitHub

## Database

The application uses MySQL to store student records. It initializes the database and student table automatically when configured correctly.

## Student Information

The system stores the following details:

- Roll Number
- Name
- Email
- Course
- Marks

## How to Run

1. Install Java JDK and MySQL.
2. Open the project in IntelliJ IDEA.
3. Add the MySQL Connector/J library to the project.
4. Configure the MySQL username and password in `DBConnection.java`.
5. Run `Main.java`.

## Project Purpose

This project was developed to practise Java programming, JDBC connectivity, SQL operations, exception handling, and input validation.
